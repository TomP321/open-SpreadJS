# @opensheets/spread-sheets-designer-resources-en

English ribbon labels, dialog text and command titles for the OpenSheets Designer component.
Importing the package registers the resources onto the designer; it must be loaded after the
designer package.

```ts
import '@opensheets/spread-sheets-designer';
import '@opensheets/spread-sheets-designer-resources-en';
```

Drop-in alias:
`{ "@mescius/spread-sheets-designer-resources-en": "npm:@opensheets/spread-sheets-designer-resources-en@^0.1.0" }`.
