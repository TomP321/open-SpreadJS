## M0 behavior and limits

Implemented: Workbook construction (sheetCount only), sheets, getSheet, getActiveSheet, destroy; Worksheet construction, name, getValue, setValue with sparse, area-separated storage; LicenseKey storage; OpenSheets productInfo; all enums. Worksheets do not render yet. No formula calculation or events. Some unsupported constructor options and method argument variants also throw NotImplemented.

React: SpreadSheets hosts a Workbook, applies worksheet names, invokes workbookInitialized, and destroys it on unmount. Host styling is supported. Other declared configuration and events throw NotImplemented when supplied; Worksheet and Column are declarative marker components. Column configuration and dynamic worksheet updates are pending.
